# PopupBanner for Evolution CMS

PopupBanner — простой всплывающий баннер для **Evolution CMS 1.4.x** с настройками через **ClientSettings**.

Текущая версия: **1.0.2**

## Возможности

- одно вертикальное изображение для desktop и mobile;
- на desktop баннер располагается по центру экрана;
- на mobile изображение масштабируется в доступную область экрана;
- задержка перед показом;
- три режима показа:
  - на каждой странице;
  - только один раз;
  - повторный показ через заданный интервал после закрытия;
- интервал повторного показа в минутах, часах или днях;
- необязательная ссылка с баннера;
- открытие ссылки в новой вкладке;
- закрытие по клику на затемнение;
- версия баннера для сброса сохранённого состояния у посетителей;
- состояние показа хранится в localStorage, отдельная таблица БД не требуется.

## Требования

- Evolution CMS 1.4.x
- ClientSettings

## Установка

Пакет предназначен для установки через **Модули → Extras → Установка из архива**.

Структура Extras:

```
install/assets/plugins/popupbanner.tpl
assets/plugins/popupbanner/css/popupbanner.css
assets/plugins/popupbanner/js/popupbanner.js
assets/modules/clientsettings/config/popupbanner.php
```

После установки:

1. Убедитесь, что в «Элементы → Плагины» появился и включён **PopupBanner**.
2. Откройте ClientSettings → **Всплывающий баннер**.
3. Включите баннер и выберите изображение.
4. Очистите кэш Evolution CMS.

Событие плагина: `OnLoadWebDocument`.
